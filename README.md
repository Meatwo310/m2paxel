# m2paxel

[GitHub](https://github.com/Meatwo310/m2paxel) | [CurseForge](https://www.curseforge.com/minecraft/mc-mods/m2paxel) | [Modrinth](https://modrinth.com/mod/m2paxel)

A Mod that adds "Paxel", a multi-tool combining Sword, Pickaxe, Shovel, and Axe functionalities, and "Phaxel", which also includes a Hoe.

## English

### Features

- 🔨 Can mine any block
- 💪 4 times the durability of regular tools (5 times for Phaxels)
- 🪓 Attack power equivalent to an axe
- ⚔️ Attack speed equivalent to a sword, with sweeping attacks
- 🌱 Phaxels can strip logs, create dirt paths, and till soil with right-click

### Recipe
Place a sword, pickaxe, shovel, and axe of the same material in the crafting grid (in any order).  
Add a hoe to craft a Phaxel, or combine a Paxel with a hoe.  
Craft a Phaxel alone to turn it back into a Paxel.

## 日本語

剣、ツルハシ、シャベル、斧の機能を併せ持つ「パクセル」と、さらにクワを統合した「ファクセル」を追加するMod。

### 特徴

- 🔨 どんなブロックも採掘可能
- 💪 通常のツールの4倍の耐久値（ファクセルは5倍）
- 🪓 斧と同等の攻撃力
- ️⚔️ 剣と同等の攻撃速度と薙ぎ払い攻撃
- 🌱 ファクセルは右クリックで原木の皮剥ぎ・道作り・耕作が可能

### レシピ
同じ材料の剣・ツルハシ・シャベル・斧をクラフトグリッドに配置(順不同)。  
クワも加えるとファクセルに。パクセル＋クワでも作成可能。  
ファクセルを単体でクラフトするとパクセルに戻せます。
